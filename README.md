# 픽셀 선거

후보 2~10명 중 한 명을 동일 확률로 뽑고, 약 30초의 픽셀 선거 쇼로 발표하는 정적 웹 앱입니다. 신문 호외와 시민들의 투표에 이어 실시간 개표, 몸싸움과 돌발 사건, 막판 접전, 당선 세리머니가 진행됩니다. 60가지 사건 중 매번 다른 조합이 등장하며, 간식 뇌물이나 커피 쿠폰 사건에 연루된 후보는 탈락할 수 있습니다. 후보의 위치는 유지하면서 그래프와 숫자로 추격을 보여줍니다. 응원 선택은 당선 확률에 영향을 주지 않습니다. 이름과 주제는 같은 브라우저 탭의 세션에 저장됩니다. 표시되는 사건·투표수·득표율은 게임 연출 데이터입니다.

당선자는 시작할 때 Web Crypto의 rejection sampling으로 먼저 정합니다. 사건과 탈락 연출은 그 결과를 보존하면서 생성하므로, 입력 순서와 관계없이 모든 후보의 당선 확률은 `1 / 후보 수`입니다. 한 판에는 최대 세 사건이 등장하며 최소 두 후보가 마지막까지 경합합니다.

## 로컬 실행

```bash
npm ci
npm run dev
```

## 검증 및 배포 준비

```bash
npm test
npm run build
npm run preview
```

Vercel에서는 이 저장소를 연결하고 Framework Preset을 **Vite**, Build Command를 `npm run build`, Output Directory를 `dist`로 설정하면 됩니다. 서버, 환경 변수, 데이터베이스는 필요하지 않습니다. 배포는 아직 실행하지 않았습니다.

## 구조

- `src/election.ts`: Web Crypto 기반 균등 추첨, 투표수 및 개표 연출 데이터
- `src/GameStage.tsx`: Phaser 픽셀 무대와 장면
- `src/game/`: 연속 장면 전환, 팔·다리 관절 캐릭터, 투표와 개표 무대
- `src/show.ts`: 30초 진행 시간과 속보 문구
- `src/storyCatalog.ts`: 6종류, 60개의 돌발 사건
- `src/BroadcastShow.tsx`: 방송 자막과 움직이는 순위표
- `src/App.tsx`: 입력, 진행, 개표 및 결과 UI

사운드, 로그인, 기록 저장, 실제 투표 및 공유 기능은 MVP 범위 밖입니다.
